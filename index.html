IndustrialBrain AI
An AI-powered platform built for the ET AI Hackathon 2026 that transforms scattered industrial documents — manuals, maintenance logs, incident reports, and SOPs — into a centralized knowledge brain. Engineers can semantically search across all documents, query a live knowledge graph of industrial assets, and get grounded AI answers through a multi-agent system. Student Notes AI Assistant
An AI-powered notes assistant that lets students chat directly with their study material. Upload a PDF or image, and ask it anything. Built using Retrieval Augmented Generation (RAG) so answers come from the actual notes — not hallucinated. Supports OCR for handwritten or scanned notes, stores embeddings in a Qdrant vector database, and serves responses through a FastAPI backend with a React frontend. Containerized with Docker for easy deployment.
✓ RAG Architecture ✓ OCR Support ✓ PDF Processing ✓ Qdrant Vector DB ✓ Docker Deployment
